# 主题资产与锚点

只读取当前目标主题对应部分。

## pixel-game

登录页或最大空白首屏必须包含：

- 晴空背景；
- 至少 2 朵像素云；
- 草地或地面；
- 树木或像素角色；
- 硬边登录面板；
- 业务安全区。

内页至少包含属性卡和 Quest / HP / EXP 语义组件。

## cyber-neon

必须包含：

- Canvas 粒子；
- 粒子连线；
- 鼠标吸引和光斑；
- 双层准心；
- 点击火花；
- 动态网格或扫描背板。

暗色背景必须使用高对比度浅色文字。

## 其他主题

读取 `templates/<主题ID>.json` 和 `design-contracts.md` 中对应章节，按当前主题定义注入资产，不加载其他主题的完整资料。
