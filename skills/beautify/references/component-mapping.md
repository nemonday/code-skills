# 业务组件映射

美化前先把业务元素映射到当前主题语义，不要只套 CSS。

| 业务元素 | 目标组件 | 处理要求 |
|---|---|---|
| 统计数字 | stat-card | 标题、数值、趋势、进度逐层迁移 |
| 排名列表 | leaderboard | 排名、主体、数值、状态分别迁移 |
| 流程状态 | steps-wrap | 节点、连线、标题、说明分别迁移 |
| 百分比 | progress-bar | 容器和填充层分别迁移 |
| 状态文字 | badge / tag | 背景、文字、边框、状态分别迁移 |
| Tab | tab | 外层 Tab、每个子 Tab、选中项分别迁移 |
| 链接 | link | 链接容器、链接文字、图标、hover 分别迁移 |
| 操作按钮 | button | 按钮表面、文字、图标、hover、focus、active 分别迁移 |
| 筛选器 | filter | 外层容器、标签、选项、选中态分别迁移 |

## 递归规则

对于任意嵌套结构：

```text
父容器 → 子容器 → 子控件 → 文字/图标
```

每一级都必须确认：

- 背景；
- 文字；
- 边框；
- 圆角；
- 阴影；
- 状态；
- 对比度。

父级样式不能作为子级已完成的证明。
